Stalled-position alerts

The Dashboard flags a position as "at risk" once it's spent more days than this in its current status. Set the threshold for each active stage below — these apply to every department and every recruiter.

Departments

The fixed department list used everywhere in the system — Manpower Plan, BU Head requests, and the coverage assignments below. Add or remove departments here; assign who covers each one underneath.

TA Leader coverage

For each TA Leader: which departments they cover (a BU Head's request in one of these departments emails them) and which Recruiters report to them. A department can be covered by more than one TA Leader; a Recruiter reports to at most one.

BU Head coverage

For each BU Head: which department(s) they can submit Manpower Plan requests for. A BU Head can be assigned more than one department.

Divisions

Top of the org hierarchy (Division > Department > Section / Cost Center). The abbreviation drives the Position ID format (MP_{Year}_{Abbrev}_{Serial}).

Department → Division assignment

Every Department must belong to a Division for the Manpower Plan cascading dropdowns and Position ID generation to work.

Sections & Cost Centers

Each Section and Cost Center belongs to one Department, and is offered in the Manpower Plan form once that Department is chosen.

Branches / Locations

Every branch has a country, which drives the salary calc's currency (EG→EGP, UAE→AED, KSA→SAR). Branch has no "Not in list" escape hatch (BR-18) — add it here first.

Position Cost Policy (§5.1.5)

The master Position list (111 real titles imported from the org chart, plus any legacy ones), and every per-position cost policy value the salary engine reads (variable salary ratio, allowances, insurance, onboarding costs). Newly-imported positions start at 0/blank on every policy field — fill them in here. Search or filter by Department/Track to find one quickly, then click it to edit its policy values inline.

Master Data Exceptions queue (BR-18)

Every "Not in list?" free-text value submitters typed instead of picking from a dropdown. Add the real value to the matching master table above, then mark it resolved.

Statutory Parameters (§5.1.5 Steps 1-2)

Egypt gross-up constants (SIS min/max, SI rates, personal exemption, the full progressive tax bracket table), versioned by year. Edit the JSON directly — this feeds the live salary calc engine on the Manpower Plan page.

Cost Visibility Settings (BR-16)

Who sees the full cost breakdown vs. just the Total Current Year Cost number. Head of HR can reassign this for any stakeholder at any time.

Delegation (Head of HR / Admin only)

Date-ranged delegation of approval authority. Once active, the delegate can act on every pending Manpower Plan line that would otherwise require the delegator, and every such action is logged as "Approved by [Delegate] on behalf of [Delegator]".

Only Admins can change these settings.
