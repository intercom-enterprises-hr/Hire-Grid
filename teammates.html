Add a teammate

Creates their login and profile in one step — no Supabase dashboard needed. They'll get an invite email to set their own password, so there's nothing to share with them yourself. Department/coverage assignment for TA Leaders and BU Heads happens afterward, in Admin Settings.

Set-up needed for invites to work

Invite emails are sent by Supabase automatically, but the link inside them needs to know where your app is hosted. In the Supabase dashboard: Edge Functions → Secrets, add SITE_URL = the address where these HTML pages live (e.g. https://intercom-enterprises-hr.github.io/Hire-Grid, no trailing slash). Then in Authentication → URL Configuration → Redirect URLs, add SITE_URL/set-password.html. This is a one-time setup step.
